# Basis Engine

### 3D simulation engine

## Getting Started

### Prerequisites

* C++20 compatible compiler
* CMake 4.3 or higher

### Building the Project

1. Clone the repository:
    ```bash
    git clone https://github.com/rusrusme/CoreEngine.git
    ```

2. Standard Build (Engine + Editor)
    ```bash
    cmake -B build
    cmake --build build
    ```
