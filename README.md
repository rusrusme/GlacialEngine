# Glacial Engine

---

## Getting Started

### Prerequisites

* C++20 compatible compiler
* CMake 3.20 or higher

---

### Building the Project

1. Clone the repository:
    ```bash
    git clone https://github.com/rusrusme/GlacialEngine.git
    ```

2. Standard Build (Engine + Editor)
    ```bash
    cmake -B build
    cmake --build build
    ```
